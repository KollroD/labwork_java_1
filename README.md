# Практическая работа 1: матрицы комплексных чисел

Консольный калькулятор матриц с комплексными элементами. Java 8+, без внешних зависимостей.

## Классы

| Файл | Назначение |
|------|------------|
| `src/Complex.java` | неизменяемое комплексное число: `+`, `-`, `*`, `/`, модуль, разбор из строки |
| `src/ComplexMatrix.java` | матрица: `add`, `multiply`, `divide`, `transpose`, `determinant`, `inverse` |
| `src/Main.java` | консольный интерфейс |

## Операции

- **Сложение** — матрицы одного размера.
- **Умножение** `A * B` — число столбцов `A` равно числу строк `B`.
- **Деление** `A / B` = `A * B⁻¹` — `B` квадратная и невырожденная, число столбцов `A` равно порядку `B`.
- **Транспонирование**.
- **Определитель** — для квадратных матриц (метод Гаусса с выбором главного элемента).

Невозможные операции дают понятное сообщение об ошибке, текущая матрица не меняется.

## Работа с интерфейсом

Сначала вводится первая матрица (размер, затем строки). Она становится *текущей*, и дальше
над ней можно выполнять операции: результат каждой операции снова становится текущей матрицей,
поэтому можно прибавить третью матрицу, четвёртую и т. д. Определитель только выводится
и текущую матрицу не меняет.

Комплексные числа записываются без пробелов: `3`, `-2.5`, `2i`, `-i`, `1+2i`, `1.5-0.5i`.
Элементы строки матрицы разделяются пробелами.

```
Current matrix (2x2):
| 1 2 |
| 3 4 |

1) add a matrix          4) transpose
2) multiply by a matrix  5) determinant
3) divide by a matrix    6) enter a new matrix
0) exit
```

## Запуск

```
javac -d out src/*.java
java -cp out Main
```
